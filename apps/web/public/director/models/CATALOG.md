# OpenReel 导演台短剧常用模型清单

这份清单是导演台项目模型库的源码合同。清单中的每一项都必须有可预览、可放置的真实 3D 模型；不接受仅有名称的占位项。

- 当前总数：**194**
- 外部资产：Kenney 官方 CC0 资产包、Khronos glTF Sample Assets
- 专用补充：OpenReel 源码组合模型，用于医疗、片场、随身物和商业设备
