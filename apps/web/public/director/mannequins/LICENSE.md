# Mesh2Motion humanoid assets

The files below are imported from
[`Mesh2Motion/mesh2motion-app`](https://github.com/Mesh2Motion/mesh2motion-app)
at commit `408db807d2d77fd2c96eb2fbd6517a7fa8106070`:

- `human-base.glb`
- `human-female.glb`
- `human-base-animations.glb`
- `human-addon-animations.glb`

Mesh2Motion publishes its art assets, including 3D models, rigs, and
animations, under the Creative Commons Zero v1.0 Universal license (CC0-1.0).
See the upstream
[`LICENSE-CC0.MD`](https://github.com/Mesh2Motion/mesh2motion-app/blob/408db807d2d77fd2c96eb2fbd6517a7fa8106070/LICENSE-CC0.MD)
and repository README for the original license statement.

The models are redistributed here with their materials overridden at runtime
to match OpenReel Studio's director-desk mannequin palette.

The two animation bundles contain 162 artist-authored clips on the same
66-bone humanoid skeleton as `human-base.glb`. Mesh2Motion credits its human
animation library to Quaternius; both projects publish these animation assets
under CC0-1.0. The files are redistributed without modifying their clip data.
